# Security

This repository is private. Report security issues through the private project
owner channel, not public issues.

For implementation policy, see:

- [Security Model](doc/SECURITY_MODEL.md)
- [Release Policy](doc/RELEASE_POLICY.md)
- [Supply Chain](doc/SUPPLY_CHAIN.md)

Do not include mnemonics, seed hex, wallet passwords, proxy credentials,
production wallet storage paths, or backup files in issue text, logs,
screenshots, traces, or support bundles.
